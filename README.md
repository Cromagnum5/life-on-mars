# Life on Mars

A browser-based real-time strategy game about corporations competing for the
resources of Mars.

## Development

```sh
npm install
npm run dev
```

Camera controls:

- `WASD` to pan
- Use the mouse wheel to zoom

Unit controls:

- Left-click a Rigwalker to select it
- Left-click and drag to select multiple Rigwalkers
- Right-click the terrain to move the selected unit or group
