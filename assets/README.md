# Game assets

`rigwalker.blend` is generated by `tools/create_rigwalker.py` and is the editable
source for `public/models/rigwalker.glb`.

Regenerate both files from the repository root:

```sh
blender --background --python tools/create_rigwalker.py
```

The GLB contains `Idle` and `Walk` animation clips. Keep gameplay and movement
logic outside the model so future visual replacements remain straightforward.
